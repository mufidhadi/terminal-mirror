# Data Dictionary & Wire Protocol Specification
## Project: Terminal Mirror (Open-Source Edition)

---

### 1. Protocol Architecture
The wire protocol uses binary **MessagePack (Named Mapping)** over WebSockets.

* **Major Version**: `1`
* **Transport**: WebSocket Binary Frames (`0x02`)
* **Serialization**: `rmp_serde` (Rust) / `org.msgpack` (Android)
* **Envelope**: `Packet`

---

### 2. Envelope Schema: `Packet`

| Field | Type | Encoding | Constraints | Description |
| :--- | :--- | :--- | :--- | :--- |
| `version` | `u16` | 2 bytes | Value: `1` | Wire protocol version. |
| `trace_id` | `String` | 36 chars | UUIDv4 | Tracing and diagnostic correlation ID. |
| `session_id` | `String` | Max 64 chars | `[a-zA-Z0-9_-]` | Target terminal session identifier. |
| `sequence` | `u64` | 8 bytes | Monotonic counter | Monotonically increasing sequence number for anti-replay verification. |
| `timestamp_ms`| `u64` | 8 bytes | Milliseconds | UTC millisecond timestamp generated by sender. |
| `payload` | `PacketPayload` | Tagged Enum | Valid variant | Inner message content. |

---

### 3. Enumerated Types

#### 3.1 `SessionRole`
Defines permissions granted to a client connected to a terminal session:
* `Admin`: Read output, send input keystrokes, request resize, receive screen snapshots.
* `Spectator`: Read output and receive screen snapshots only. Keystrokes are rejected.

---

### 4. Payload Variants (`PacketPayload`)

#### 4.1 `RegisterHost`
Published by Host Daemons when establishing session availability on Relay Hub.

| Field | Type | Description |
| :--- | :--- | :--- |
| `host_id` | `String` | Unique hardware / workstation UUID. |
| `os_type` | `OsType` | `MacOS`, `Windows`, `Linux`, or `Android`. |
| `hostname` | `String` | Workstation friendly name (e.g. `MacBook Pro M1`). |
| `token` | `String` | Pre-shared relay token or authentication signature. |
| `public_key` | `Option<String>`| Host's static X25519 public key (Base64). |

#### 4.2 `SubscribeSession`
Published by Mobile Client to attach to a session.

| Field | Type | Description |
| :--- | :--- | :--- |
| `client_id` | `String` | Unique mobile client instance identifier. |
| `session_id` | `String` | Target session identifier. |
| `auth_token` | `String` | Authentication token or persistent device signature. |
| `requested_role` | `SessionRole` | Desired access level (`Admin` or `Spectator`). |

#### 4.3 `ScreenStateSync` (New)
Published by Host upon client reconnection to restore visual terminal grid state.

| Field | Type | Description |
| :--- | :--- | :--- |
| `snapshot` | `ScreenSnapshot` | Full visual grid containing lines, cursor position, and alternate screen flag. |

#### 4.4 `ScreenSnapshot` Struct (New)

| Field | Type | Description |
| :--- | :--- | :--- |
| `cols` | `u16` | Grid width in columns. |
| `rows` | `u16` | Grid height in rows. |
| `cursor_x` | `u16` | Cursor column index (0-indexed). |
| `cursor_y` | `u16` | Cursor row index (0-indexed). |
| `in_alternate_screen` | `bool` | `true` if application (e.g. `vim`, `htop`) is using alternate screen buffer. |
| `lines` | `Vec<String>` | Array of rendered text lines matching the visible viewport. |

#### 4.5 `PairWithPin` (New)
Published by Mobile Client to initiate pairing with a headless host using a 6-digit PIN.

| Field | Type | Description |
| :--- | :--- | :--- |
| `pin` | `String` | 6-digit numeric string (e.g. `491023`). |
| `client_public_key` | `String` | Base64-encoded client X25519 public key. |

#### 4.6 `PairingConfirmed` (New)
Returned by Host Daemon confirming association and providing long-lived authentication token.

| Field | Type | Description |
| :--- | :--- | :--- |
| `success` | `bool` | Confirmation status. |
| `host_name` | `String` | Friendly name of host machine. |
| `host_public_key` | `String` | Base64-encoded host X25519 public key. |
| `auth_token` | `String` | Long-lived cryptographically signed token for 1-tap reconnections. |

#### 4.7 `SessionRevoked` (New)
Broadcast by Host when the physical emergency kill switch (`Ctrl+Shift+Q`) is triggered.

| Field | Type | Description |
| :--- | :--- | :--- |
| `reason` | `String` | Reason string (e.g. `"Revoked by host physical kill-switch"`). |

### 5. Persistent Local Entities

#### 5.1 `TrustedDevice`
Stored in `authorized_devices.toml` (Host) and Android KeyStore (Mobile Client).

| Field | Type | Description |
| :--- | :--- | :--- |
| `device_id` | `String` | Unique hardware identifier of paired peer. |
| `friendly_name` | `String` | Display name (e.g. `"ThinkPad Windows"`, `"Mufid Pixel Phone"`). |
| `public_key` | `String` | Base64-encoded X25519 public key. |
| `last_relay_url`| `String` | Last used relay URL. |
| `paired_at_ms` | `u64` | UTC epoch millisecond timestamp of pairing. |
